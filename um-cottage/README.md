# UM Cottage Project

## Overview
The UM Cottage project is a web application designed to manage and display information about various rooms available for rent. Each room has its own dedicated page that provides details such as amenities, photos, and descriptions.

## File Structure
The project consists of the following files:

- **index.html**: The main page of the application that displays a table of rooms with tenant names and links to view each room.
- **room1.html**: Contains specific details about the first room, including amenities and descriptions.
- **room2.html**: Provides unique information about the second room.
- **room3.html**: Details specific to the third room.
- **room4.html**: Information about the fourth room.
- **room5.html**: Features and offerings of the fifth room.
- **room6.html**: Unique attributes of the sixth room.
- **room7.html**: Relevant information about the seventh room.
- **room8.html**: Specific details regarding the eighth room.

## Usage
1. Open `index.html` in a web browser to view the list of rooms.
2. Click on the "View Room" link for any room to see more details on its respective page.
3. You can update tenant names directly in the table on the main page, and the changes will be saved in local storage.

## Future Enhancements
